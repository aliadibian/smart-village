# روستای هوشمند

پروژه‌ی درسی: «نقش سواد فناورانه در زندگی روستایی»

سایت با React و Vite ساخته شده و سه بخش داره:

- **روستای هوشمند** — نقشه‌ی SVG دست‌ساز روستا با ۹ جای قابل کلیک (مزرعه، آبیاری، مدرسه،
  درمانگاه، بازار، خانه‌ها، دکل اینترنت، طبیعت، انرژی خورشیدی). با کلیک روی هر کدوم،
  دوربین به همون نقطه می‌ره و پنل مقایسه‌ی «بدون سواد فناورانه / با سواد فناورانه» باز می‌شه.
  توی صحنه آسیاب بادی چرخان، بادکنک، پل چوبی، گوسفند، مرغ، مرغ‌آبی، پروانه و... هم هست.
- **مسابقه‌ی دانایی** — ۱۰ سؤال چهارگزینه‌ای، هر کدوم ۱۰ امتیاز. اسم می‌گیره، جواب رو
  همون لحظه توضیح می‌ده و آخرش جدول امتیاز نشون می‌ده. هر نفر فقط یک بار می‌تونه شرکت کنه.
- **نجات مزرعه** — بازی ۶۰ ثانیه‌ای با canvas: با پهپاد قطره‌های آب رو جمع کن، از لوله‌های
  خراب دوری کن تا رطوبت مزرعه برسه به ۱۰۰٪. کیبورد (←/→ یا A/D)، موس، لمس و
  دکمه‌های لمسی موبایل — همه پشتیبانی می‌شن. مکث با P یا دکمه‌ی HUD؛
  با مخفی شدن تب بازی خودش متوقف می‌شه.

## اجرا

```bash
npm install
npm run dev      # http://localhost:5173
```

برای ساخت نسخه‌ی نهایی:

```bash
npm run build    # می‌ره توی dist/ (یک فایل index.html کامل)
npm run preview
```

هیچ متغیر محیطی لازم نیست؛ بدون `.env` هم کار می‌کنه.

## ساختار کد

```
src/
├── components/
│   ├── village/        # صحنه‌ی روستا (شکسته به تیکه‌های کوچیک)
│   │   ├── VillageScene.tsx   # چیدمان صحنه + دوربین و پارالاکس
│   │   ├── Hotspot.tsx        # ناحیه‌ی قابل کلیک هر مکان
│   │   ├── sceneBits.tsx      # درخت، ابر، گل، پروانه و...
│   │   └── props.tsx          # آسیاب، پل، جانورها، تابلو و...
│   ├── quiz/           # اجزای مسابقه (کنفتی، گیج امتیاز، پنل معلم)
│   ├── LocationPanel.tsx
│   ├── Leaderboard.tsx / GameBoard.tsx
│   ├── Nav.tsx / icons.tsx
├── game/               # موتور بازی «نجات مزرعه» — جدا از React
│   ├── engine.ts       # حلقه‌ی بازی، برخوردها و ورودی‌ها
│   ├── draw.ts         # همه‌ی ترسیم‌های canvas
│   ├── audio.ts        # صداها با Web Audio
│   ├── constants.ts / types.ts
│   └── useFarmGame.ts  # پل بین موتور و رابط React
├── hooks/              # useMediaQuery، useReducedMotion
├── pages/              # سه صفحه‌ی اصلی
├── data/               # اطلاعات مکان‌ها و سؤال‌ها
└── lib/                # ذخیره‌سازی، قفل تک‌تلاش، اعداد فارسی
```

نکته‌ی معماری: موتور بازی هیچ چیزی از React نمی‌دونه؛ فقط callback می‌ده.
نوار وضعیت بازی (امتیاز، زمان، رطوبت) هم هر فریم مستقیم روی DOM آپدیت می‌شه
تا React وسط حلقه‌ی بازی رندر اضافه نکنه.

## محدودیت یک تلاش

قفل داخل مرورگر نگه داشته می‌شه (localStorage)، یعنی **هر دستگاه یک بار**. موقع شروع
مسابقه قفل زده می‌شه، نه موقع تموم شدن، بنابراین رفرش کردن یا بستن تب فایده‌ای نداره.

اگه بخواید جدی‌ترش کنید، یک سرور کوچیک لازمه: توی `.env` مقدار
`VITE_QUIZ_API_URL` رو بدید، اون‌وقت سایت قبل از شروع می‌ره آی‌پی عمومی رو برمی‌داره
(SHA-256 می‌کنه، خود آی‌پی جایی ذخیره نمی‌شه) و از سرور می‌پرسه اجازه داره یا نه.
اگه سرور در دسترس نباشه، مسابقه بدون مشکل ادامه پیدا می‌کنه تا ارائه‌ی کلاسی وسط کار نیفته.

> فقط حواستون باشه توی متغیرهای `VITE_` نذارید رمز و کلید؛ همه‌شون توی کد عمومی
> بسته‌بندی می‌شن. `DATABASE_URL` و اینا فقط سمت سرور.

## جدول امتیاز

از `localStorage` استفاده می‌شه، یعنی جدول مال همون مرورگره و بین دستگاه‌ها مشترک
نیست. اگه بعداً بخواید مشترک بشه، کافیه توی `src/lib/storage.ts` یک پیاده‌سازی دیگه از
`LeaderboardStore` بنویسید و `leaderboard` رو عوض کنید — رابط کاربری نیازی به تغییر نداره.

## چند نکته‌ی فنی

- React 19 + Vite 7 + Tailwind 4، راست‌چین (`dir="rtl"`, `lang="fa"`)
- فونت‌ها: Lalezar و Vazirmatn از Google Fonts
- نقشه‌ی روستا کاملاً دست‌نویس SVG هست، تصویر خارجی نداره که خراب بشه
- آدرس هر بخش با hash قابل اشتراک‌گذاریه (`#quiz`، `#game`)
- انیمیشن‌ها به `prefers-reduced-motion` احترام می‌ذارن
- صدا فقط بعد از اولین کلیک ساخته می‌شه (autoplay نداره) و وضعیت بی‌صدا هم ذخیره می‌شه
